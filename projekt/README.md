# Witaj 👋

Aplikacja promująca spontaniczność i autentyczność.

## Zaczynajmy

1. Sklonuj repozytorium

   ```bash
   git clone https://github.com/Ivisii/JPUM.git
   cd projekt
   ```

2. Zainstaluj zależności

   ```bash
   npm install
   ```

3. Utwórz plik .env w głównym katalogu z Twoimi kluczami supabase

4. Uruchom projekt

   ```bash
   npx expo start
   ```

   i zeskanuj kod QR

## Użyte technologie

~Expo Go, React
~Expo Router
~Supabase (PostgreSQL, Auth API)
~expo-camera, expo-location
~Context API, React Hooks
~React Async-Storage
